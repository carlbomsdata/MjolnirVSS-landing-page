Put the whole disk back.

An image of a Windows system disk, taken while Windows is running, that can be written onto a blank disk after the old one fails.

No installer, no service, no driver. Delete the folder and it is gone.

It has never restored a real computer.

Every figure on this page was measured in a virtual machine. Treat MjolnirVSS as something to test on a machine you can afford to lose, and keep the backup you already have.

How it works

One disk, captured whole, while you carry on using it.

Taken live

Microsoft's shadow copy service freezes the disk for the instant it takes to start a snapshot. The copy is read from that frozen view.

Only what is in use

Free space is not copied. On one measured machine that was 2.9 million clusters out of 16.5 million.

Verified before it is trusted

Every stored block is read back and checked against its digest. Only then is the backup marked complete.

What has been run

Four operating systems, backed up, restored, and started.

Windows 10 22H24.75 GB storedbooted
Windows 11 24H218.28 GB storedbooted
Windows Server 20194.44 GB storedbooted
Windows Server 20256.10 GB storedbooted

Each restored machine started unaided, matched 12 of 12 file hashes, and kept every partition's identifier, offset and size.

When the disk has failed

Boot the media, choose the backup, type the disk's serial number.

MjolnirVSS builds its own recovery media from the Windows parts this computer already has. The drive holding the backup cannot be chosen, and nothing is erased until you have typed the phrase exactly.

The limits

What it will not do.

  • Run on anything but UEFI with a GPT system disk
  • Capture data that lives on any disk but the system one
  • Take incremental backups
  • Keep BitLocker switched on through a restore
  • Offer you a download, because there is no release yet
