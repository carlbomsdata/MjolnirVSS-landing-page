Windows 10, 11 and Server · v0.1.0-alpha.1

Copy the disk Windows runs from. Put it back on a new one.

MjolnirVSS images a whole Windows system disk while Windows is running, and writes that image onto a blank replacement disk after the original has failed.

One executable. No installer, no service, no driver. Deleting the folder removes it.

No real computer has been restored with it.

Every number on this page was measured in a virtual machine. Test it on a machine you can afford to lose, and keep the backup you have.

How it works

The disk is copied while you keep working.

Snapshot, not downtime

Windows freezes the disk for the moment it takes to open a shadow copy. MjolnirVSS reads from that frozen view, so nothing has to stop.

Used clusters only

Free space is skipped. One test machine held 2.9 million clusters in use out of 16.5 million, and only those were read.

Checked before it counts

Every block is read back and compared against its BLAKE3 digest. A backup that fails that check is never marked usable.

Restoring

Boot the media. Pick the backup. Type the disk's serial number.

MjolnirVSS builds its own recovery media from the Windows recovery files already on the machine. The drive holding the backup is excluded, and nothing is erased until the serial number is typed exactly. The wizard runs from the keyboard alone.

Test results

Four operating systems, each backed up, restored and started.

Windows 10 22H24.75 GB storedstarted unaided
Windows 11 24H218.28 GB storedstarted unaided
Windows Server 20194.44 GB storedstarted unaided
Windows Server 20256.10 GB storedstarted unaided

Each restored machine matched 12 of 12 file hashes and kept every partition's identifier, offset and size. Windows Server 2022 was not tested.

On a server

Your existing backups are left alone.

MjolnirVSS declares a copy backup, not a full one. Microsoft's rule: a copy backup "doesn't constitute a base backup for further differential backup operations", and "log files should never be truncated as a result of a copy backup". Running it does not move SQL Server's differential base or truncate Exchange's logs.

Limits

What it will not do.

  • Run on anything but UEFI with a GPT system disk
  • Copy data that lives on any disk but the system one
  • Take incremental backups
  • Leave BitLocker switched on through a restore
  • Offer a download — there is no release yet
